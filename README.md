# RetroNet

RetroNet, 90’ların internet kültüründen yola çıkan bir sohbet projesi. İlk açılışta sizi 1999’un web tasarımı ve o dönemin dünyasından konuşan bir karakter karşılıyor. “Modernleştir” düğmesine bastığınızda ise hem arayüz hem de sohbetin bakış açısı 2030’a geçiyor.

Bu projede eski web sitelerinin havasını yeniden oluşturmak ve aynı uygulama içinde iki farklı dönem deneyimi sunmak istedim. Python ve FastAPI ile hazırlanan uygulama, Gemini üzerinden yanıt üretiyor; arayüzde sade HTML, CSS ve JavaScript kullanılıyor.
